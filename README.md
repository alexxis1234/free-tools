# FreeTools — 100-tool SEO build

Architecture: React + Vite, reusable components, browser-side tool implementations, category pages and static SEO pages.

## Tools
- 50 Text tools
- 46 Developer tools
- 4 Image converters
- 100 working tools total

## Required converters included
- WebP → PNG
- CSV → JSON
- XML → JSON

## Run
`npm install`
`npm run dev`

## Production build
`npm run build`

The build generates static SEO pages, sitemap.xml and robots.txt. The current SEO scripts use the FreeTools Cloudflare Workers URL as the canonical base URL.
