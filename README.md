# FreeTools — fixed 30-tool SEO MVP

Architecture: React + Vite, reusable components, one implementation file per tool, category pages and static SEO pages.

## Tools
- 15 Text tools
- 12 Developer tools
- 3 Image converters

## Run
`npm install`
`npm run dev`

## Production build
`npm run build`

The build generates static SEO pages, sitemap.xml and robots.txt. Replace `https://YOUR-DOMAIN.example` in the SEO scripts with the real domain before deployment.
